# 验收网页浏览检查

改了 `assets/acceptance-report/` 或生成器的展示部分时，用 `python3 scripts/sample_report.py <目录>` 生成示例页，在浏览器里逐条核对。桌面版 Claude 的内置浏览器对本机文件只显示快照、不能点击，要用本机预览服务打开示例目录。

1. 首屏：标题、一句话结论、你要做的事和预计分钟、验收员检查的数量分布、这次改了什么，都和数据一致。
2. 请你试：一项一行，纵向排列；步骤编号；要打开的网页是带箭头的文字链接，点了在新标签页打开那个页面；反引号里的命令带"复制"按钮，点了显示"已复制"；"应该看到""算没做对"；缩略图能放大。
3. 验收员已检查：需关注的排在前面；"需关注"筛选只剩未通过和无法验证；点条目打开侧栏，上一项、下一项只在筛选结果里切换；Esc 先关放大图再关侧栏，焦点回到原条目。
4. 证据：每份先写"这说明……"；截图能放大、看原尺寸、左右键切换；文本证据只显示关键行和行号，全文默认收起，展开后关键行有底色；"打开原文件"可用，HTML、SVG、脚本只能下载、不会执行。
5. 已知问题、技术细节（默认收起）、页脚的检查对象和生成时间正确；没有内容的部分不显示。
6. 390 像素宽：整页没有横向滚动，侧栏占满宽度，日志在自己的框里横向滚动。
7. 数据坏了时显示"暂时无法读取这个验收网页"；控制台没有报错；页面不加载任何外部网址。
8. 亮暗跟随看板：在示例看板（`sample_board.py` 生成，coding-pal 示例的"pal 合并命令"带"打开验收网页"链接）选暗色，再打开验收网页是暗色；选亮色是亮色；跟随系统时随系统。暗色下请你试、侧栏、日志、放大看图的文字都看得清。要在 Chrome 里用 `file://` 打开检查：本机预览服务的网址和 `file://` 各存各的选择。
